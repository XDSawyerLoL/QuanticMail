# Contact-specific distributed permission (lab)
Local keys remain independently provisioned; they are no longer sufficient for native mail release. Own identity's classical and PQ roots sign a distinct, checkpoint-bound contact permission covering exact address/device and SHA256 pins of all four public keys, monotonic version, explicit active state and bounded validity (24h). Each witness accepts signed grants locally through contact_permission.py, persists permanent denial, refuses replacement, rollback, fork and reactivation. Broker adds exact contact commitment to the normal fresh quorum precheck after consent and durable journal CAS before any outgoing envelope or incoming plaintext is returned. All accepted votes echo exact commitment. Existing own-device authorization remains required. Revoking contact at three witnesses is tested without removing local key file; independent own PQ revocation tested subsequently using a new device proof. No automatic grant distribution, global contact identity authority or remote contact's own revocation feed yet. Same single-host lab threat model; contact commitments are linkable within a witness and request timing remains observable. CI pending. No production deployment.
