# Scheduled detached proof distribution (lab)
Opt-in --dual-proof-feed requires compact scheduled registry; persists a mode marker to refuse older feed configuration. Fixed 256 byte request, 8192 byte response each poll (previous response 2048). Encapsulates existing compact signed lease plus optional exact 3309 byte detached ML-DSA-65 signature, strict framing and padding. Root pins still installed independently; no remote root installation, signing or administrative endpoint. Signed lease decoded, detached proof staged with both signatures, grant applied and durable state committed in one transaction. Missing or wrong proof invalidates cache; no vote-triggered fetch. Network fixture distributes grant/proof pair through existing mTLS carrier rather than modifying witness proof tables directly. Tests pending CI. Existing 2048 mode still supported outside explicit dual feed. Physical timing and increased carrier capacity need measurement; no production deployment, root rotation or real account migration. Broker independently checks root commitment but relies on witness signature verification.
