# Direct native signature verification (lab)
Mandatory extra argument to PQ broker: absolute private local JSON file with sequence, classicalRoot and PQRoot DER SPKIs, classicalSignature (64-byte raw P-256 R||S), PQSignature (3309-byte ML-DSA-65); byte arrays standard Base64. No private material. Classical root tied to 128-bit canonical address, PQ root independently pinned by existing argument. Native Go verifies classical signature, OpenSSL EVP verifies PQ signature over exact canonical grant/checkpoint ID. Every successful quorum vote must match the locally verified active sequence and existing exact digest. New sequence requires restart with updated local proof. Local proof does not prove latest revocation; witness quorum still necessary. Local files must be provisioned via trusted channel; not yet automatic client proof delivery. Network fixture tests corruption of each signature independently; fixed pacing regression corrected null-success callback assertion. No production release or actual account migration. Linux tagged backend only; stub refuses PQ verification.
