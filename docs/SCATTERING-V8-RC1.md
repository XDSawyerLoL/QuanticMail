# Quantic Scattering V8.0 RC1 — laboratory integration, not release approval

This draft adds the locally tested fixed-size cell carrier and the V7.1.5 temporal module. No production caller is modified. Node 22, existing Quantic manifests, independent encryption of three copies, 168-byte native spool format. The separate downloadable RC1 archive includes the complete experimental runner, native Linux and Windows binaries and source, historical Java receiver, test harnesses, traces and audit. The lab runner uses standard mutual TLS 1.3 with synthetic device certificates, full key pins and local 3-of-4 witness checks, tunneled over two existing native UDP pacers. Pre-shared experimental outer secret and epoch salt are provisioned in a single controller. There is no distributed authority or production bootstrap. The 4-second synthetic wire epochs and 2.5-second refresh offset are accelerated, not the temporal module's 30s/5s configuration. The temporal module and Java persistent replay store are separately tested, not wired into the TLS harness.

51/51 Node unit cases passed (45 inherited plus 6 new); all four historical Java suites executed successfully. Five 10-second, 5ms loopback campaigns:
- active: 10/10 synthetic messages, 1998 and 1997 datagrams, max gaps 86.09/87.71ms.
- idle: 0 messages, two handshakes, 1992/1998 datagrams, max gaps 102.85/100.17ms.
- perturbed: 10/10 synthetic messages; deterministic receiver injection of 302 drops, 214 alterations and 192 duplicates; 1968/1967 datagrams measured before impairment.
- revocation: established TLS session closed on scheduled refresh, next epoch refused, coverage continued (1974/1977).
- untrusted certificate: no mutually authenticated connection or delivery; handshake did not complete, two server hangups, coverage continued (1964/1966).
Every observed datagram was 168 bytes. Perturbation and wrong-cert runs concurrent on same host. No estimate of global intrusion probability or inference resistance. The tested carrier has no robust flow/retransmission protocol; losses of all redundant copies can stall TLS. Its disk spool, replay state, keys, scheduling, and authority assumptions are not production-ready. Do not activate on actual identities, expose network endpoints or merge as a production transport. Remaining gates: independently administered authenticated witnesses and rollback anchoring; production identity/key provisioning, robust reliable carrier, durable idempotent delivery, integration of guarded deadlines with actual transport, cross-host encrypted authorization and synchronization, Windows and physical network tests with independent observer, and independent security review including endpoints, application authorization, supply chain and confidentiality analysis.
