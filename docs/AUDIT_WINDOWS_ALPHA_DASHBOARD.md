# Windows operator dashboard
The packaged launcher opens a real WinForms dashboard (Windows PowerShell 5.1, STA), with 12 explicit actions. It routes operations to the existing verified launcher with fixed operation names and constrained paths, then returns to the window after terminal confirmation. No secret fields, browser, remote login, plaintext logs, direct HTTP fallback, background automatic enrollment or destructive migration. The existing file-based and mailbox workflows still require independently configured synthetic identities, authority quorum, transport and relay; the bridge still requires separate pacer/sink and epoch provisioning. No claim that the GUI or config creation is production ready. CI parses all scripts and instantiates the packaged dashboard, tests field states and argument constraints; no interactive physical Windows validation. No installation or signature is produced by this change.
