# V7.1.3 — manifest-bound session laboratory

This module uses the actual QuanticMail manifest validator and canonical encoding, with synthetic root-signed manifests. The authority callback must supply independently authenticated, current snapshots (manifest, sequence, digest, validUntil); it is NOT implemented by this module. Root and device signing SPKI SHA-256 pins must have been securely provisioned. The module rejects legacy short identifiers, root/device key reuse, stale or invalid snapshots, and future authorization.

Mutual transcript signatures bind peer addresses, device IDs, manifest digests and ephemeral X25519 keys. HKDF derives separate directional AES-GCM keys. Every prove/finish/seal/open operation rechecks both authorities, using a lease of at most 60 seconds and a session lifetime of at most 5 minutes. Any observed manifest change or authority outage closes the session irrevocably. Traffic keys stay in the process; best-effort zeroization does not guarantee memory erasure. Per-direction counters and an in-memory replay set protect this test session; fresh handshakes use new keys.

Run: node --test tests/scattering-manifest-session.test.mjs (14 tests, Node 22). The laboratory frame format is NOT the native 168-byte V7.1.1 transport. There is no production integration, no network handshake, no authenticated authority service, no post-quantum claim, and no independent cryptographic audit. The test callback is a mutable in-memory map. An old signed snapshot can still be accepted in a NEW session if the whole trusted authority is rolled back or lies; deployed revocation propagation and a durable rollback-resistant authority are mandatory. Revocation applies at the next local operation after receipt of the new trusted state, not instantly across a disconnected network. This prototype must not transmit identity-bearing hello fields publicly. A standard authenticated key exchange and encrypted control channel, fixed-size framing, native bridge/replay state and physical/Windows audits remain production gates.
