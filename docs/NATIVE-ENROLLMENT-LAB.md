# Native enrollment preflight laboratory
Run node --test tests/native-enrollment.test.mjs. All eight tests passed locally on Node 22.16, using the four unchanged main manifest modules. This module has no production callers. It validates a fresh linked-device signing key proof bound to the pinned root, exact existing manifest sequence/digest, both candidate public keys, label, nonce and short expiry. It checks a trusted caller's explicit approval flag, then requires a valid root-signed manifest with exactly the intended addition. It always reports safeToRemoveOldKeys:false and hardwareAttested:false. It is NOT a migration implementation, not a hardware attestation verifier, and not proof of possession of the ECDH encryption key. The approval flag is not a trusted UI by itself. Clock and process restart attacks, durable freshness and concurrent publish are not fully addressed. Before production: verified native TPM device proofs and native ECDH, trusted local consent, independent current authority, CAS publish + readback, recovery and historical-message access test, key-provider refactoring and safe revocation/rotation. Never delete the existing root private key: canonical identity depends on it. Existing copied keys cannot be made uncompromised retroactively.
