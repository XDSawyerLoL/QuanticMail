# Native single-file laboratory installer
The native Windows package is embedded in an NSIS user-level EXE. Immutable build-specific install path under LocalAppData, no existing installation overwrite, no vault data migration, no legacy registry edits, no autostart or firewall changes. Start menu shortcut passes the CI-built inventory and vault pins to the verified launcher. CI installs silently, independently checks extracted inventory, refuses duplicate installation, verifies unchanged payload and confirms unsigned EXE fails publisher gate. No production publication, no certificate generated or trust store modified. The unsigned lab installer requires trust in its independently obtained artifact hash before executing. Commercial signing requires a real publisher code signing certificate and a trusted timestamp; the separate Test-Native-Installer-Signature.ps1 gate checks Authenticode and the independent publisher certificate pin. NSIS availability and successful CI must be confirmed before a download is offered. No uninstaller is included in this laboratory build; no automatic destructive cleanup.

Windows CI 44942406610 completed portable validation but lacked the assumed preinstalled NSIS tool. Build with the official MSYS2 UCRT64 NSIS package via the existing authenticated package manager, using the explicit toolchain executable and Windows paths; keep actual install/reinstall and signature-refusal tests in PowerShell. No change to publisher trust requirements.

Operator signing path: Sign-Native-Lab-Installer.ps1 in a trusted source checkout takes the independently verified unsigned installer SHA256, a new output EXE, independently pinned publisher certificate SHA256, a valid Microsoft-signed SDK SignTool and an explicit HTTPS RFC3161 timestamp endpoint. Only an existing CurrentUser/My code-signing certificate with its private key is eligible. Explicit approval, no overwrite, verify copied input, sign separate output, verify Authenticode/timestamp/publisher pin. No secret is printed or placed in the repository. Do not distribute a failed output. CI parses the script and rejects unsigned installers; actual signing requires the publisher's certificate and has not been performed. This signs a lab installer, not a production security approval.
