# Windows native desktop bridge — experimental
The trusted Node controller now supports an explicit Windows-only PQ laboratory configuration, with native NTFS custody for controller key, contacts and peer TLS inputs. A trusted installer directory and independently obtained binary SHA-256 are mandatory. The helper is a bounded local process, not a service, and cannot read the vault key files, journal or result cache. The broker retains local console consent, exact key pins, quorum and signed-controller protocol. The Windows dialog path is isolated from the existing Web renderer. It supports opening authenticated wire files and preparing encrypted wire files, including explicit exact recovery; never issues mailbox acknowledgements. Existing Electron 38 remains gated because Node 24 is required. A separate Node 24 terminal entry point supports the same operations now. No Windows installer, physical test, signed runtime dependency bundle, trusted enrollment or migration is claimed. Binary dependency trust and executable TOCTOU rely on a trusted installation directory and OS; a compromised same-user process is outside this model.
