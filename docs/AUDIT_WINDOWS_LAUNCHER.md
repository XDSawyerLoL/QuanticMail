# Windows laboratory launcher regression
The last packaged workflow tested the verifier and individual executables but not the launcher. Source inspection found duplicate fragments introduced by replacement of PowerShell patterns containing dollar characters. Rebuilt the launcher from a clean literal source; preserve independent pins, full inventory verification and explicit local lab scope. CI must parse both packaged PowerShell files and successfully run the Providers and ProbeLoopback operations through the real launcher, refusing both wrong manifest and wrong binary pins. No production accounts, installer signing or native enrollment implied. Previous artifacts should not be represented as runnable through the broken launcher.
