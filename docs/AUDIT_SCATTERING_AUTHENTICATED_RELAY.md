# Authenticated mailbox over native Scattering, integrated regression
The existing real relay integration regression now supports an explicit Linux native-carrier mode. Two different links provide independent random epoch/secret pairs, private queues, spent-epoch markers, separate pacers and sinks (eight native processes total). All mailbox calls use the relevant local bridge; the actual relay listens on loopback behind the remote ends. Relay restart preserves its listening port. Real classical and ML-KEM hybrid ciphertext, both sender signatures, four mTLS signed checkpoint authorities, identity-token binding, exact retry/digest, conflict rejection, pull/decryption, ACK, recover across relay restart, contact revocation, and failure after link shutdown are exercised. Dedicated CI invokes this test in addition to the ordinary non-carrier integration. Still synthetic software keys (Node crypto, not native Go vault operations), no independent physical hosts or real accounts. Direct mTLS authority traffic is not covered by the mailbox link. No metadata-privacy or production readiness claim.
