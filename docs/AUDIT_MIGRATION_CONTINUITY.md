# Read-only active-device continuity gate
Compare the original verified public manifest against a newer signed hybrid snapshot obtained for both old and new devices from a trusted authenticated peer source. Require matching current manifest and profile digests/sequences, independent root pins, preserved old device keys, no resurrection of previously revoked devices and a distinct linked candidate matching four independently obtained new public key pins. No registry changes, no account migration, no deletion. The regression uses four independent Ed25519 attestation keys and valid signed synthetic manifests/profiles. It does not prove physical device custody, previous PQ-root continuity where no original PQ profile exists, nor authorize cutover. A caller must independently authenticate peerSource and the two root pins. No live account is modified.
