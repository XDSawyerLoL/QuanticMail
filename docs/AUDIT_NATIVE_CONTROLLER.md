# Native local controller, migration P0
This branch now contains a Node-only client of the existing Go compact-quorum broker. It checks an independently provided executable hash, the pinned signing and encryption SPKI hashes, and a private local Ed25519 controller key. Only explicit static-envelope open and enrollment-domain signing are exposed, authenticated pipes, one command at a time, no fallback.
Not wired to Electron remote renderer or web server. Do not expose the API to remote JS. Local operator supplies private config and approves on independent terminal. The artifact hash check assumes a trusted installation directory; it is not operating-system attestation. Controller can read returned plaintext and is trusted. Classical static mode only, no sender-authentication claim. Historic unlabeled, hybrid and one-time-prekey packets deliberately refused; uncertain response may consume a journal entry. 
PQ migration: allow 128-bit device identifiers in public proposal, profile and hybrid routing validation without changing canonical signed fields for older 40-bit identifiers. No PQ secret has been migrated, and no production registration or key deletion. Native enrollment signature proves possession of a candidate signing key, not authority to replace the historical root. Keep original data. Actual native executable is in the laboratory delivery; source and packaging integration are still required.

Terminal entry point: node scripts/native-vault-local.mjs /absolute/config.json open-static /absolute/envelope.json /absolute/new-result.json (or sign-enrollment with the exact challenge text). Config contains labOnly:true and the absolute paths/pins required by connectNativeVault. Private output created exclusively before the operation; a failed or interrupted request may leave an empty/partial file. No existing output is overwritten. Keep inputs until recovery is verified. Requires a controlling terminal and the independently provisioned laboratory binary.
