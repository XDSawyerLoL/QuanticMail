# Native relay mailbox — bounded local integration
The existing standalone RelayRuntime now persists a nativeMailbox extension in the same V3 snapshot; no parallel account store. Explicitly enabled via startRelayServer({host:"127.0.0.1",nativePeerSource:...}), using the existing independently configured createAttestedPeerSource. No production env default. POST /api/quantic/native/v1/send, pull, ack, recover; local trusted client, no browser origin, no CORS, bearer token must match exact strong device, fresh server-side authority verification (both peers for send) plus real sender signatures required. Only canonical, strictly bounded encrypted native record stored; no authority bundles or raw tokens. Duplicate exact record yields same ID/digest after restart; same sender/device/clientMessageId with different record refused even after ack. Recipient-scoped pull/ack/recover. Ack only marks mailbox acknowledgement, not proof of opening; ciphertext retained for explicit recovery. Max 256 total rows, fails closed at cap, no eviction, no indefinite production retention policy. Reuse exported file on retry, not native signing again. Queue commit before HTTP success under existing runtime storage semantics. No guarantee for crash between Go journal commit and file export or after native decrypt before UI display. Single local relay only; old binaries can discard new extension, no deployment or migration; actual client transport and signed recipient receipts still needed. Existing storage multi-process/rollback caveats apply. Native route cannot be exposed to Internet without authenticated transport; loopback reverse proxy also requires separate protection. Tests use actual generated signed native records, controlled checkpoint source, real HTTP and file state restart; additional combined real Go + authority + relay scenario outstanding.

Follow-up: scripts/serve-native-mailbox.mjs explicitly launches existing local relay/runtime with configured pinned authority source; Node 24 with --experimental-transform-types, --local-native-relay absolute private JSON config (dataDir,port,authority). Bounded client exposes send/pull/ack/recover; UI transmit only; no automatic ack or receipt proof. Local HTTP is not a cryptographically authenticated transport against malicious local processes. Use only trusted loopback lab. Retry test uses actual client after restart. No production release.
