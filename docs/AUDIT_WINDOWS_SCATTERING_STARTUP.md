# Packaged runtime regression
The two Windows runs on efeeee3 (44939446531 and 44939441930) passed all eight Go and nine client tests but failed on the guard startup before UDP traffic. Strong hypothesis: the raw CI binary was in RUNNER_TEMP, whereas its DLL was in MSYS2; the trusted child intentionally removes the toolchain PATH. The previously validated portable artifact already includes native OpenSSL next to its executable. Move the real UDP test after packaging, use packaged binaries and restricted PATH, retain all ACL and binary pin checks, add bounded exit status diagnostic. No assertion of root cause or successful fix until CI runs. Do not relax child PATH or skip tests.
